# 天机一线 v0.3.56

《天机一线》浏览器公开试玩仓库。

## 运行方式

本项目使用 GitHub Pages + GitHub Actions 发布。完成 Pages 首次启用并上传 `tianji-yixian-v0.3.56-web.zip` 后，部署工作流会自动解压并发布静态网页。

- 游戏版本：v0.3.56
- 运行：纯浏览器 HTML/CSS/JavaScript
- 存档：浏览器 localStorage
- 访问者：无需 GitHub 账号
- 预计公开地址：https://aughost1983.github.io/tianji-yixian/

## 部署

仓库已包含 `.github/workflows/pages.yml`。Pages 的 Source 请设置为 **GitHub Actions**。
